    How it works

    Does this find all personal data?

    No. It only replaces strings you list. Anything you did not list stays in the output; review the full text.

    Do case and spaces matter?

    Yes. Matching is case- and space-sensitive. Targets must be one line; line breaks and control characters are rejected. Leading and trailing spaces stay, with no Unicode normalization. The longest matching target at each position wins.

    Is my text uploaded?

    The text is processed in this browser tab and is not submitted to the tool service by design. There is no cloud storage or automatic recovery; reloading clears the text.
