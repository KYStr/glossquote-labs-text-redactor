# 品牌規格：自訂文字遮蔽

狀態：SPEC_ONLY；沒有使用者研究、視覺或可用性證據。

繁中「自訂文字遮蔽」，英文 “Custom Text Redactor”。Gloss Tools by GlossQuote 的產品署名。文字應避免「完全匿名化」「消除個資」「保證安全」等絕對聲明。固定輸出 token 為 [REDACTED]，中英文一致。

品牌語氣尊重、直接、沒有恐慌。主要視覺關係是來源、明確列出的 targets、處理結果三者可分辨；不把結果包裝成安全徽章。固定的人工檢查警示是產品核心，不可摺疊或只放在 FAQ。

沿用 Gloss Tools 共通 Product App design system；工作表面在視覺上優先於品牌裝飾。錯誤與風險同時使用文字、icon、顏色，不以顏色 alone 顯示遮蔽狀態。
